# 🎬 StudioSpace
### Find Your Space. Create Your Story.

> A creative space marketplace built for creators, by creators.

🌐 **Live Website:** https://studio-space-frontend-lilac.vercel.app

## ✨ About
StudioSpace helps creators discover and book creative spaces.
Explore studios for photography, filmmaking, podcasting, music, and more.

## 🚀 Features
- Browse and explore creative studios.
- Search studios by category and location.
- View studio details, pricing, and amenities.
- Register and log in with email or Google.
- Add and manage personal studio listings.
- Book studios and manage reservations.
- Access a personalized user dashboard.
- Secure authentication with protected routes.
- Responsive design for different devices.
- Light and dark theme support.
